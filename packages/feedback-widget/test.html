Instructions

  1. Start the Next.js dev server: pnpm dev
  2. Go to admin UI → hub → Widget → generate an API key
  3. Replace sk_YOUR_KEY in the script tag at the bottom with your real site key
  4. Serve this directory on another port (e.g. npx serve packages/feedback-widget -l 5173) and add that origin to Allowed Origins
  5. Click the "Feedback" button in the bottom-right
